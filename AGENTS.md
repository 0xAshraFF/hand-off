# Handoff agent guide

Handoff turns a job, quantity, budget, priority and owned tools into one practical execution route and a concise agent Markdown handoff. Preserve the React/Vite/Express V2 implementation; do not rebuild without a concrete architectural reason.

Run existing typecheck/build/tests and inspect the app first. This file is manually initialized because /init is unavailable through this desktop tool session. ## Facts and catalog
THE LLM IS NOT THE DATABASE. Current prices, tiers, API/region availability, subscriptions, restrictions and benchmark claims must come from sourced catalog data. Never invent facts or verification timestamps. Source priority: official API, official pricing, official docs, documented trusted aggregator, manual verification. Reachability does not verify pricing. Preserve old values on fetch/parser failure; record failures, price and offer history, last_verified_at, source health and stale flags. Exclude expired offers. Keep fast cached snapshots; design durable Postgres/Supabase migrations for providers, tools, models, capabilities, pricing, price_history, free_tiers, subscriptions, offers, offer_history, source_urls, source_checks, quality_evidence, benchmarks, model_routes, regions and catalog_tags.

## Recommendations
Decompose tasks, query relevant candidates, deterministically filter capabilities/access/privacy/hardware/region, calculate costs, route within the TOTAL budget, optionally call a model-agnostic OpenAI-compatible selector/planner, then validate selections server-side and recalculate costs. Reject nonexistent or task-ineligible IDs; ignore model-supplied prices. Provider nationality/name never earns preference points. Chinese providers, Western providers, open source/local and SaaS are first-class candidates.

Free first favors adequate owned tools, confirmed eligible free tiers and local routes before paid usage. Best value means sufficient quality at the lowest sensible incremental cost. Quality first upgrades only important tasks and explains extra spend. Owned subscriptions are $0 incremental only in supported access modes; subscriptions never grant API credits. Separate API/project usage, recurring subscriptions, existing tools, free tiers, hardware and unknown credit prices. Unknown never means zero; a known subtotal does not establish budget feasibility. Verified rates with estimated workloads remain estimates.

## UX
Dark navy/graphite, restrained amber, blue info tags, teal success, thin borders, strong typography, generous spacing; functional light/mobile/tablet. Home: What will you make happen? then quantity/budget/priority/tools; advanced privacy/hardware/access/region collapsed. Explore browses outcomes with actual search/filters and Cmd/Ctrl+K. Never show fabricated counts, costs, deals or tested claims. Prepare/Make/Check/Publish tasks show tool/provider, purpose/output, cost, reason, secondary alternatives, sources/check dates and evidence. Video separates scripting, visuals, voice, editing, QA and publishing. Every plan supports copy/download .md with goal, ceiling, tools, route, constraints and task validation. Human output stays concise. No competitor/reference-product mentions in UI, comments, docs, metadata or seeds.

## Engineering and collaboration
Isolate adapters; keep secrets server-side; validate and bound requests; enforce planner/fetch timeouts; degrade safely on catalog failure. Prefer deterministic code and stored facts over LLM calls. API: catalog/search/tools/prices/plan/refine/offers/status plus authenticated refresh. Preserve snapshots atomically and retain full histories.
Main agent owns architecture, difficult pricing/planner/security decisions, integration, review and verification. Use bounded independent subagents aggressively when supported, with disjoint files and minimal context. Prefer Luna for routine research/docs/frontend/schema; Sol for reasoning/security/pricing/evaluation. Review all patches; never rediscover catalog facts with a model.
