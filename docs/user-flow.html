A prescription for model usage, in the shape of a game box

The first question sets how deep the app goes. The last question decides whether it needs a model at all. In between, a first-timer answers two questions in fifteen seconds and still walks out with the same spec sheet everyone else gets — just fewer columns of it.

Free pathno login · uncapped · ~$0 per run
Metered pathsign-in · 3 per day · one model call

The whole flow

The badges on each step say who sees it: N for a first-timer, I for the default, H for Hug Me. Filled means the step is shown.

The spec sheet

The back of the game box. Same jobs down the left, three builds across the top, a verdict at the bottom. Nobody has to know what a model is called to read it.

Where the catalog comes from

The recommendation is a pure function only because the numbers are already on disk when the request lands. Nothing in the flow above ever calls a benchmark API live.

Screen by screen

Screen 00 · the gate

How deep do you want to go?

  • Three cards, no jargon, no self-assessment
  • Just tell me what to use — two questions, one column
  • Show me the options — the full six steps, three columns
  • Hug me — adds local and Hugging Face builds

Sets how many steps appear, and how many columns the spec sheet shows.

Screen 01 · all tiers

What are you building?

  • Six tiles, icon and one line each
  • Selecting auto-advances — no Next button

Sets which jobs appear as rows on the spec sheet.

Screen 02 · I and H

Where does it run?

  • Cloud, local, hybrid, or stays on my machine
  • A hard filter, not a preference

First-timers skip it — cloud is assumed.

Screen 03 · I and H

What does it handle?

  • Multi-select: text, images, PDFs, audio, video, code
  • Needs a confirm button, unlike single-select steps

First-timers skip it — inferred from the tile at step 1.

Screen 04 · all tiers

What can you spend?

  • Slider, $0 to $500, month or run
  • Labelled in plain language, not numbers alone

Sets the verdict row at the bottom of the spec sheet.

Screen 05 · I and H

What matters most?

  • Three sliders totalling 100 — quality, speed, cost

First-timers skip it — balanced is assumed.

Screen 05b · H only

What hardware have you got?

  • VRAM, so the GGUF quant can be sized to fit
  • The only screen that assumes real technical knowledge

Unlocks the Hugging Face column on the spec sheet.

Screen 06 · the fork

Describe it in your own words

  • Optional free text, hard cap of 150 words
  • Counter turns amber at 130, blocks at 150
  • Skip is weighted equally to submit

Skip → free path. Write → sign-in, quota, one model call.

Free path

Scored on the spot

  • Deterministic scoring over the cached catalog
  • No sign-in, no quota, no model call
  • The entire first-timer journey lives here

Straight to the spec sheet.

Metered path

Sign in, then analyze

  • Google sign-in on first visit only
  • Three runs a day
  • A cheap flash model, chosen from our own catalog
  • Out of runs falls back to the free path, never a wall

To the analyzing state, then the spec sheet.

Screen 07

Your spec sheet

  • Three tiers across, the same jobs down
  • Cost per month and a fits / over budget verdict
  • First-timers see the Recommended column only
  • Any cell expands to show why that model won

To the handoff, or back to any chip to re-answer.

Screen 08

Your handoff

  • Default tab is prose for Claude or ChatGPT
  • It names the models and says keys will be needed
  • Their assistant handles the setup from there

To save or share — both optional, both off by default.

What the analyzer costs

Roughly 1,500 tokens in and 400 out. The fixed system prompt and schema are about 1,200 of those and identical on every call, so prefix caching takes most of the input cost to nearly nothing.

Don't hardcode the analyzer. Store it as a row in the same catalog and let the same scoring function pick it, for the job "classify short text into a fixed schema, as cheaply as possible". It then updates itself every night. A model-recommendation product that pins its own model is the one bug reviewers will never let go of.

"Lyken" returns nothing I can verify. It may be too new to index, or spelled differently. That is the strongest argument yet for the live catalog: neither of us can hold this list in our heads, and the search did surface real free models — Nemotron 3 Ultra, Laguna S 2.1, Ling 3.0 Flash Fin, Inkling Small — that most people on Claude have never heard of. Those are exactly the names this product exists to put in front of them.
